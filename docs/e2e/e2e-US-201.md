# E2E Test Design (US-201)

## 対象
- Playwright (`tests/e2e`)
- 重要ジャーニー: notes 作成/更新/表示/検証/認可

## 観点とシナリオ

| シナリオID | 観点 | 手順概要 | 期待結果 |
|---|---|---|---|
| E2E-201-01 | 作成・永続化 | 設定画面で notes 入力→保存→再読み込み | 同一 notes が再表示される |
| E2E-201-02 | 更新反映 | 既存 notes を更新→保存→一覧へ遷移 | 一覧/設定画面とも更新値が見える |
| E2E-201-03 | 一覧表示制御 + 既存互換 | notes あり/なし Website を作成して一覧表示 | notes ありのみ表示、なしは非表示。notes 未設定データでもエラーなく表示 |
| E2E-201-04 | 省略表示 | 長文 notes を保存して一覧表示 | 省略表示される（全文強制表示しない） |
| E2E-201-05 | 上限検証 | 501 文字入力して保存 | 保存失敗、上限超過エラー表示 |
| E2E-201-06 | 認可 | 権限なしユーザーで更新 API 実行 | 401 で拒否、変更されない |
