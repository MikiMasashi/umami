# E2E テスト設計: US-201（ウェブサイトのメモ）

- 対象: `tests/e2e/notes.spec.ts`
- ランナー: Playwright（`playwright.config.ts`, `testDir: ./tests/e2e`, `testIdAttribute: 'data-test'`）
- 前提: 実行には稼働中の umami サーバ + DB が必要。本フェーズでは `--list` による収集のみ確認する。

---

## 1. テスト観点

| 観点 | 内容 |
| --- | --- |
| 正常系（入力・保存・永続化） | 設定詳細でメモを入力・保存し、再読込後も保持される |
| 一覧表示 | メモありは一覧に表示、メモなしは表示されない（従来どおり） |
| 境界値 | 500 文字ちょうどは保存可、501 文字は不可 |
| セキュリティ | 上限超過はサーバ 400、権限なしはサーバ 401（クライアントバイパス不可） |
| 編集（クリア） | 保存済みメモを空にして未設定へ戻せる |
| 後方互換 | メモ未設定サイトの一覧・詳細・リネームが従来どおり動作 |

## 2. シナリオ ↔ 受入条件トレーサビリティ

| シナリオ（spec の test 名） | 主な確認 | AC | FR/NFR |
| --- | --- | --- | --- |
| AC-1/AC-2: enter, save and persist notes… | 入力→保存→再読込で保持 | AC-1, AC-2 | FR-1, FR-2 |
| AC-3: the list shows notes… | 行に `website-notes` が表示され本文を含む | AC-3 | FR-4 |
| AC-4: the list shows no notes cell… | メモなし行に `website-notes` が無い | AC-4 | FR-4, FR-6 |
| AC-5: 500-character limit can be saved | 500 文字保存成功・エラー無し | AC-5 | FR-3 |
| AC-6: over 500 characters is rejected | UI エラー文言表示 + サーバ 400 | AC-6 | FR-3, NFR-2 |
| AC-7: without update permission… (401) | view-only ユーザの更新が 401、値不変 | AC-7 | FR-5, NFR-2 |
| AC-9: clearing notes… | 空保存後に一覧で非表示 | AC-9 | FR-7 |
| AC-8: legacy website keeps working | 一覧/詳細/リネームが従来どおり | AC-8 | FR-6 |

網羅: AC-1〜AC-9 の全 9 条件を E2E でカバー（AC-1 と AC-2 は 1 シナリオに統合）。

## 3. 設計上の工夫（安定化）

- セレクタは `data-test`（`input-notes` / `button-submit` / `website-notes`）と行スコープ
  （`page.locator('tr', { hasText: '<site name>' })`）を用い、CSS/XPath 依存を排除。
- web-first assertion（`toHaveValue` / `toContainText` / `toHaveCount`）で自動待機し、
  明示的 sleep を使わない。
- テストデータは各テストで一意な名前・ドメインで作成し、`finally` で `deleteWebsite`
  により後始末（並列実行・再実行に耐える）。AC-7 は作成した view-only ユーザも削除。
- サーバ側の権限・バリデーションは API 直呼び（`request.post`）で検証し、クライアント
  バイパス経路（AC-6, AC-7）を明示的にテストする。

## 4. 契約依存（実装フェーズが満たすべき外部観測点）

- ルート: `/settings/websites/{websiteId}`（詳細）, `/settings/websites`（一覧）
- DOM: `input-notes`（textarea 内包）, `button-submit`, `website-notes`（非空行のみ）
- 文言: `Notes must be 500 characters or less.`
- HTTP: `POST /api/websites/{id}` に `notes` を受け、501→400 / 権限なし→401
