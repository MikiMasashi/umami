# US-202（ユーザーストーリー生の要望）

> サイト管理者として、登録している各ウェブサイトに「担当者の連絡先メールアドレス」を
> 登録しておきたい。サイトが増えると、障害や問い合わせのときに誰へ連絡すればよいのかが
> 名前とドメインだけでは分からなくなるから。

## 要望（生の言葉）

umami に登録したウェブサイトごとに、**連絡先メールアドレス**を1つ持たせてほしい。

- ウェブサイト設定の詳細画面（Settings → Websites → 対象サイトの編集）で、
  連絡先メールアドレスを入力・変更・保存できる。
- 保存した値は永続化され、画面を再読み込みしても入力欄に残っている。
- メールアドレスとして成立しない文字列は保存させない。保存できなかったことが画面で分かること。
- 空欄のままでも保存できる（必須ではない）。一度入れたものを空欄にして保存すれば、
  未設定に戻せること。
- 既存のウェブサイト（未設定のもの）でも、これまでどおりエラーなく表示・更新できること。
- ウェブサイトを更新する権限がないユーザーが、この項目だけを書き換えられてはいけない。

保存先やフィールド名、UI の文言・配置は、既存の実装スタイル（TypeScript・Next.js App Router・
zod・Prisma・`@umami/react-zen`）になじむ形にすること。

## 今回はやらないこと（スコープ外）

検証コストを抑えるため、以下は**明確にスコープ外**とする。実装・テストとも対象にしない。

- ウェブサイト**一覧**への表示、検索・絞り込み・並べ替えへの反映
- ウェブサイト**新規追加フォーム**への項目追加（追加時は未設定でよい）
- このアドレスへの通知・メール送信などの機能
- 新しい画面・新しいエンドポイントの追加（既存の編集画面と既存の更新 API に載せる）
- 多言語メッセージの追加（画面ラベルは既存の翻訳済みラベルを流用してよい）
