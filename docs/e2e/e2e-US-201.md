# E2E Test Design - US-201

## Scope
- Playwright によるクリティカルジャーニーのみ
- 詳細バリデーション境界値はコンポーネントテストへ寄せる

## Target routes
- `/websites`
- `/websites/{websiteId}/settings`

## Scenarios

### US-201-1 メモ新規入力・保存・再読み込み
1. notes 未設定 website を作成
2. `/websites/{websiteId}/settings` を開く
3. `data-test="notes-input"` に入力
4. `data-test="notes-save-button"` を押下
5. `メモが保存されました` を確認
6. 再読み込み
7. 同じ内容が表示されることを確認

### US-201-2 一覧画面でメモ表示
1. notes あり website / notes なし website をそれぞれ用意
2. `/websites` を開く
3. `data-test="website-notes-cell-{websiteId}"` で表示確認
4. notes なし website は空表示確認
5. 長文 note は省略表示確認

### US-201-4 権限なしユーザー編集不可
1. 閲覧専用権限ユーザーでログイン
2. `/websites/{websiteId}/settings` を開く
3. `data-test="notes-input"` が read-only/disabled
4. `data-test="notes-save-button"` が非表示または disabled
5. 直接 API 呼び出しで `POST /api/websites/{websiteId}/notes` を実行
6. `401` を確認

## Out of scope for E2E
- 500/501 文字境界
- Zod error payload の詳細構造
- 省略ロジックの pure function 確認

## Stability policy
- 各 test で独立 website を seed
- cleanup を各 test で実施
- CSS selector 不使用
- `data-test` と role ベース使用
- Playwright auto-wait + web-first assertions 使用
