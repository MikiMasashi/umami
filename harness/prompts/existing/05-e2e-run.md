# フェーズ: E2Eテスト実施（既存プロセス）

あなたは E2E テストの実施を担当します。**必ず `test-engineer` スキルを使って**作業してください。
対象プロジェクト: **{{PROJECT_NAME}}**

## 入力（既存の成果物を読むこと）
- `{{SOURCE_E2E_TESTS}}` 配下の Playwright テスト
- `{{DOCS_E2E}}/e2e-{{STORY}}.md`

## やること
1. E2E テストを実行する。
2. 各受入条件の合否を対応表に反映する。
3. 失敗があれば原因を切り分けて報告する（**実装は勝手に修正しない**。欠陥検出の記録が目的）。

## 出力
- `{{DOCS_E2E_RESULTS}}/e2e-result-{{STORY}}.md` … 実行結果・受入条件ごとの合否・検出した欠陥の一覧

## 制約（検証の再現性のため厳守）
- `stories/{{STORY}}/acceptance-criteria.md` … このファイルは検証時に使用するものなので**絶対に読み込まないこと**
- {{SOURCE_IMPL}} の実装やテストの内容は変更しない（結果の記録のみ）。
- 受入条件ファイルは編集しない。
- 完了したらコミットする（メッセージ: `[{{STORY}}] e2e result`）。
