# US-201 E2Eテスト設計（Website Notes）

## 1. テスト観点
- **保存・永続化**: 設定画面で入力した notes が保存され、再表示・再読み込み後も保持されること。
- **入力制約**: 501文字以上の notes を保存できず、利用者に上限超過が伝わること。
- **一覧表示**: notes あり行のみ表示され、長文は省略表示で可読性を維持すること。
- **権限制御**: 更新権限のないユーザーは notes を更新できず、既存値が不変であること。
- **後方互換**: notes 未設定（null）データで一覧・詳細・更新が継続動作すること。

## 2. E2Eシナリオ
| シナリオID | 種別 | 目的 | 主な確認内容 |
|---|---|---|---|
| E2E-US201-01 | UI + API | notes の保存と一覧表示 | 設定画面保存、再読み込み保持、一覧の notes 表示、長文省略、notes 未設定行の非表示 |
| E2E-US201-02 | UI | 文字数上限超過の拒否 | 501文字入力で保存拒否、上限エラーメッセージ表示、既存値が維持される |
| E2E-US201-03 | API | 権限なし更新拒否 | view-only ユーザーの更新が 401、対象 notes が未変更 |
| E2E-US201-04 | UI + API | notes 未設定データの互換性 | 一覧取得・詳細取得・更新処理が null notes で正常動作 |

## 3. 受入条件トレーサビリティ
| 受入条件 | カバーするシナリオ | カバー内容 |
|---|---|---|
| AC-01 設定画面での保存 | E2E-US201-01 | 設定画面で notes を保存し、リロード後も同値を確認 |
| AC-02 文字数上限 | E2E-US201-02 | 501文字入力で保存拒否とエラー表示を確認 |
| AC-03 一覧表示（notes あり） | E2E-US201-01 | notes あり行で表示されること、長文省略（title 保持 + オーバーフロー）を確認 |
| AC-04 一覧表示（notes なし） | E2E-US201-01 | notes 未設定行で notes 表示領域が出ないことを確認 |
| AC-05 権限制御 | E2E-US201-03 | 更新権限なしユーザーの更新拒否とデータ不変を確認 |
| AC-06 既存データ互換 | E2E-US201-04 | notes null で一覧/詳細/更新が正常継続することを確認 |

## 4. Playwright テスト仕様
- 実装ファイル: `tests/e2e/website-notes-us201.spec.ts`
- 実行コマンド: `npm run test:e2e -- website-notes-us201.spec.ts`
- 設計方針:
  - API でテストデータを独立生成し、UI は検証対象導線に集中させる。
  - セレクタは `data-test` と行フィルタ中心で実装依存を最小化する。
  - `expect` による web-first assertion を使用し、固定 sleep を使わない。

## 6. セルフレビュー結果
- 受入条件 AC-01〜AC-06 の対応が 1 つ以上の実行シナリオで明示され、欠落なし。
- 正常系（保存/表示）と異常系（上限超過/権限拒否）を分離し、失敗時の原因切り分けが可能。
- 長文省略は「表示要素の title とオーバーフロー」の両観点で検証し、視認要件に沿う形にした。
- notes 未設定データに対して一覧・詳細・更新を通しで確認し、後方互換リスクを抑えた。
