# Data Specification Review (US-201)

## 結論
- 採用: `website.notes VARCHAR(500) NULL` を追加。

## 重点レビュー観点
1. 既存データ互換: nullable により既存レコード無変更で移行可能。
2. サイズ妥当性: 要件上限 500 と DB 制約を一致させ二重防御。
3. 検索/ソート影響: 既存一覧性能に影響を与えない（notes 検索は対象外）。

## 懸念点
- 将来 notes 検索要件が追加された場合はインデックス・全文検索方針が必要。

## 代替案と却下理由
- 代替案: `TEXT` 型で上限なし運用。
- 却下理由: 要件（500 文字上限）と乖離し、UI 表示制御・不正入力抑止が複雑化するため。
