## 8. 環境セットアップの推奨手順

### 前提条件
- Node.js 22.x
- pnpm 10.15.1
- PostgreSQL 15 (Docker Compose で起動可能)
- 環境変数の設定

### 実行手順

```bash
# 1. リポジトリをクローン
git clone <repository-url>
cd umami

# 2. 依存関係をインストール
pnpm install

# 3. 環境変数を設定
cp .env.example .env
# .env を編集してデータベース情報を設定
# DATABASE_URL=postgresql://umami:umami@localhost:55432/umami

# 4. Docker でデータベースを起動（オプション）
docker-compose up -d db

# 5. Prismaクライアントをビルド
pnpm build-db

# 6. データベースマイグレーション実行
pnpm exec prisma migrate deploy

# 7. E2E テストを実行
pnpm test:e2e
```
